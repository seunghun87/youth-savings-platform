## 2. 서비스 배포

Render에 두 서비스를 올려 **실제로 접속 가능한 서비스**가 되었습니다.

| 서비스 | 역할 | 리전 |
|---|---|---|
| `youth-savings-web` | 프론트엔드 (정적 사이트) | 글로벌 CDN |
| `youth-savings-backend` | API 서버 | 싱가포르 |

### 플랫폼별 제공 전략

iOS는 앱 설치에 macOS와 유료 개발자 계정이 필요해, **같은 코드를 웹으로 제공**하는 방식을 택했습니다.

| 플랫폼 | 방식 | 사용자가 하는 일 |
|---|---|---|
| iOS | 웹 (Safari) | 링크 열기 → 공유 → 홈 화면에 추가 |
| Android | 웹 또는 APK | 링크 열기 → 홈 화면에 추가 |
| PC | 웹 | 링크 열기 |

**링크 하나로 배포가 끝납니다.** 파일 전송이나 설치 허용 절차가 필요 없습니다.

### 배포 과정에서 해결한 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| Blueprint 동기화 실패 | 두 서비스가 서로의 주소를 참조하는 순환 구조 | 주소는 배포 후에야 정해지므로 직접 입력 방식으로 변경 |
| 리전 변경 거부 | 기존 서비스가 다른 리전에 존재 | 서비스 재생성으로 싱가포르 확보 (한국에서 응답 150~200ms 개선) |
| 백엔드 기동 실패 | 필수 환경변수 미입력 | 입력 절차를 1차/2차로 분리해 문서화 |
| 동기화 API 500 오류 | 마이그레이션 미적용 | 적용 순서를 문서에 명시 |
| Blueprint 위치 인식 실패 | `render.yaml`이 하위 폴더에 위치 | 저장소 루트로 이동 |

### 보안 설정

- 앱(WebView)의 출처는 고정값이므로 서버에서 항상 허용 — 설정 누락으로 앱이 API를 못 부르는 사고를 방지
- 출처 문자열 정규화 — 스킴 누락, 끝 슬래시 등 흔한 입력 실수를 흡수
- 동기화 API는 비밀키 필요, 요청 빈도 제한, 프록시 뒤 IP 식별 설정

## 3. 청년 대상 적금이 누락되던 문제

**이번 구간에서 가장 중요한 수정입니다.**

### 발견

금융감독원 API의 가입제한 코드(`join_deny`)로 상품을 걸러내고 있었는데, 실제 데이터 26건을 확인한 결과 **절반 이상이 청년이 가입할 수 있는 상품**이었습니다.

특히 아래 세 건은 **서비스의 핵심 대상 상품인데도 목록에서 통째로 빠져 있었습니다.**

| 상품 | 가입대상 |
|---|---|
| NH1934월복리적금 | 만 19세 ~ 만 34세 |
| 청년플랜적금 | 만 19세 이상 ~ 만 39세 이하 |
| 청포도 청년적금 | 19 ~ 39세 |

그 밖에도 가입대상이 "제한없음"인데 제한 코드가 붙은 상품, 직장인·무주택·첫거래처럼 청년도 충족 가능한 조건의 상품이 함께 걸러지고 있었습니다.

### 원인

가입제한 코드의 "일부제한" 값에는 성격이 전혀 다른 조건이 뒤섞여 있습니다.

> 반려견을 키우는 고객 / 만 19세~34세 개인 / 중소기업 근무자 / 무주택자 / 첫거래 고객

코드 하나로는 구분할 수 없는 것들입니다.

### 해결

판정 기준을 코드가 아닌 **실제 가입대상 문구**로 바꾸고, "청년 개인이 혼자 충족할 수 있는가"만 봅니다.

- **부양 대상 조건 제외** — 반려동물·자녀·미성년·출산·한부모 등
- **연령 상한이 19세 미만인 경우 제외** — "39세 이하"(청년 상품)와 "15세 이하"(아동 상품)를 숫자로 비교해 구분

**결과: 제외 26건 → 10건.** 남은 10건은 자녀·반려동물 대상뿐입니다.

> 검증: 운영 데이터의 제한 상품 전체를 테스트에 그대로 넣어, 규칙을 수정해도 판정이 깨지면 즉시 드러나도록 했습니다.

## 4. 신규 기능

### 저축액 배분

월 저축액을 여러 상품에 나눠 담았을 때의 결과를 보여줍니다. 한 상품의 월 한도를 넘는 금액을 다음 상품으로 넘기므로, 한 곳에 몰아넣는 것보다 이자가 커집니다.

백엔드는 완성돼 있었으나 화면에서 호출하는 코드가 없었습니다.

- 상품별 배분 비율·금액·적용 금리·적용 기간
- 예상 세후 이자 합계
- 상품 한도를 다 채워도 남는 금액이 있으면 안내

### '그 외의 적금' 코너

자녀·반려동물 등 조건이 붙어 추천에서 제외한 상품도 **어떤 조건인지와 함께 소개**합니다. 조건에 해당하는 사용자는 직접 확인할 수 있습니다.

접힌 형태로 두어 기본 목록을 가리지 않으며, 가입할 수 없는 상품이므로 저장·가입 동작은 두지 않았습니다.

### 아이폰 홈 화면 앱

메타 태그와 아이콘만으로는 실사용에서 어긋나는 부분이 있어 함께 보정했습니다.

| 문제 | 조치 |
|---|---|
| 전체화면 실행 시 헤더가 노치·상태바에 가림 | 상단 안전 영역 여백 적용 |
| 입력창 탭 시 화면이 확대되고 되돌아오지 않음 | 터치 기기 입력창 글자 크기 상향 |
| 탭 하이라이트·고무줄 스크롤 등 웹 티 | 제거 |
| 사용자가 홈 화면 추가 방법을 모름 | iOS Safari에서만 안내 배너 1회 노출 |

앱 아이콘(홈 화면·브라우저 탭용)을 서비스 상징에 맞춰 제작했습니다.
